2.3 建表 SQL 示例

-- 启用 pgvector 扩展
CREATE EXTENSION IF NOT EXISTS vector;

-- 用户表
CREATE TABLE users (
    user_id         SERIAL PRIMARY KEY,
    username        VARCHAR(50) UNIQUE NOT NULL,
    password_hash   VARCHAR(255) NOT NULL,
    name            VARCHAR(50) NOT NULL,
    role            VARCHAR(20) NOT NULL CHECK (role IN ('super_admin','admin','teacher','student')),
    department      VARCHAR(100) NOT NULL,
    education_level VARCHAR(10) DEFAULT NULL,
    grade           VARCHAR(10) DEFAULT NULL,
    admin_scope     VARCHAR(100) DEFAULT NULL,
    school_id       VARCHAR(20) DEFAULT NULL,
    email           VARCHAR(100) DEFAULT NULL,
    is_active       BOOLEAN DEFAULT TRUE,
    is_first_login  BOOLEAN DEFAULT TRUE,
    login_attempts  INT DEFAULT 0,
    locked_until    TIMESTAMPTZ DEFAULT NULL,
    last_login      TIMESTAMPTZ DEFAULT NULL,
    delegate_to     INT DEFAULT NULL REFERENCES users(user_id),
    delegate_until  TIMESTAMPTZ DEFAULT NULL,
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_users_role ON users(role);
CREATE INDEX idx_users_department ON users(department);

-- 审计日志表
CREATE TABLE audit_logs (
    log_id          SERIAL PRIMARY KEY,
    operator_id     INT NOT NULL REFERENCES users(user_id),
    operator_name   VARCHAR(50) NOT NULL,
    action          VARCHAR(50) NOT NULL,
    resource_type   VARCHAR(50) NOT NULL,
    resource_id     INT DEFAULT NULL,
    detail          JSONB DEFAULT NULL,
    ip_address      VARCHAR(45) DEFAULT NULL,
    user_agent      VARCHAR(500) DEFAULT NULL,
    created_at      TIMESTAMPTZ DEFAULT NOW()
);

CREATE INDEX idx_audit_operator ON audit_logs(operator_id);
CREATE INDEX idx_audit_action ON audit_logs(action);
CREATE INDEX idx_audit_time ON audit_logs(created_at);
CREATE INDEX idx_audit_resource ON audit_logs(resource_type, resource_id);

4.3 数据隔离规则

角色数据可见范围
super_admin全部数据，无限制
admin仅自己管辖范围内的项目（如学生处管理员只能看到奖学金类申请）
teacher仅自己学院学生的申请，仅自己发布的政策
student仅自己提交的申请，仅符合自己学历+学院+年级的政策

4.4 RBAC 中间件实现方案

实现方式：FastAPI 依赖注入（Dependency Injection）
核心逻辑： 
# 角色校验装饰器
def require_roles(roles: list[str]):
    async def dependency(current_user = Depends(get_current_user)):
        if current_user.role not in roles:
            raise HTTPException(403, "无权限访问")
        return current_user
    return dependency

# 使用示例
@router.get("/admin/users", dependencies=[Depends(require_roles(["super_admin"]))])
async def list_users():
    ...

@router.get("/teacher/reviews", dependencies=[Depends(require_roles(["super_admin", "teacher"]))])
async def list_reviews(current_user = Depends(get_current_user)):
    # current_user.department 用于数据隔离
    ...

5.2 页面详细设计

5.2.1 登录页

页面要素
  • 用户名输入框（Element Plus el-input）
  • 密码输入框（type="password"，显示/隐藏切换）
  • "记住我"复选框（可选，记住用户名）
  • 登录按钮（加载状态）
  • 登录失败时显示错误提示（Element Plus el-alert）
  • 首次登录成功后跳转到修改密码页

交互细节：

  • 输入框 trim 去除首尾空格
  • 密码错误时不清空已输入的用户名
  • 登录成功后 Token 存 localStorage，跳转到首页
  • 登录失败 5 次后显示"账号已锁定，请 15 分钟后再试"

5.2.2 修改密码页

页面要素
  • 当前密码输入框
  • 新密码输入框（含密码强度指示器）
  • 确认新密码输入框
  • 提交按钮

密码强度规则：

  • 至少 8 位
  • 至少 1 个大写字母
  • 至少 1 个小写字母
  • 至少 1 个数字
  • 至少 1 个特殊字符（!@#$%^&*）
  • 强度指示器：弱（仅满足长度）/ 中（满足 3 条）/ 强（满足全部）

5.2.3 用户管理页（超级管理员）

页面要素
  • 顶部：搜索框（按用户名/姓名搜索）+ 角色筛选下拉 + 状态筛选 + "创建用户"按钮 + "批量导入"按钮
  • 主体：Element Plus el-table，展示用户列表
  • 表格列：用户名、姓名、角色、学院、年级、状态（启用/禁用）、最后登录时间、操作
  • 操作列：编辑、启用/禁用、重置密码
  • 分页：el-pagination，每页 20 条

创建用户弹窗：

  • el-dialog 表单：用户名、姓名、角色（下拉）、学院、学历、年级、邮箱
  • 创建成功后自动生成初始密码，在弹窗中展示（一次性，关闭后不再展示）

批量导入弹窗：

  • 步骤 1：下载模板 → 上传 Excel 文件（拖拽上传）
  • 步骤 2：预览解析结果（前 20 条 + 总数）
  • 步骤 3：确认导入 → 展示导入结果

5.2.4 审计日志页

  • 表格：操作时间、操作人、操作类型、资源类型、资源 ID、IP 地址、详情
  • 详情列支持展开查看 JSON 详情

  • 右侧：通知铃铛图标（未读数量角标）

八、本阶段边界场景

场景处理方式
用户名不存在提示"用户名或密码错误"，不区分具体哪个错
密码错误超过 5 次锁定账号 15 分钟，锁定期间正确密码也拒绝
账号被禁用提示"账号已被禁用，请联系管理员"
Token 过期自动用 Refresh Token 刷新，刷新失败则跳转登录页
Token 被篡改JWT 签名校验失败，清除 Token，跳转登录页
批量导入中部分数据格式错误跳过错误行，继续导入其他行，返回失败详情
批量导入文件中用户名重复与已有数据重复 → 跳过；与本次导入数据重复 → 取最后一条
批量导入文件格式不对提示"文件格式错误，请下载模板后重试"
创建用户时用户名已存在提示"用户名已存在"
删除自己（超级管理员删除自己的账号）禁止删除，提示"不能删除自己的账号"
禁用自己禁止禁用，提示"不能禁用自己的账号"
并发登录（同一账号多处登录）允许多设备同时登录，但 Token 各自独立
修改密码时旧密码错误提示"原密码错误"
修改密码时新密码与旧密码相同提示"新密码不能与旧密码相同"
登录时用户名带空格前端 trim 去除首尾空格
