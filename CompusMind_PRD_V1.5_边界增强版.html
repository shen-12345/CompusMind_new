第3章 功能需求与边界分析

3.1 用户认证模块

3.1.1 功能描述

系统提供基于账号密码的登录与身份识别功能，支持角色权限隔离。

3.1.2 功能细节

功能点描述
用户登录输入用户名和密码进行登录
身份识别登录后识别用户角色，加载对应权限视图
密码修改首次登录强制修改初始密码；支持自行修改密码
会话管理登录后保持会话，超时自动退出

3.1.3 边界条件

场景处理方式
用户名不存在提示"用户名或密码错误"（不区分具体哪个错，防止账号枚举）
密码错误超过5次锁定账号15分钟，锁定期间即使正确密码也拒绝登录
未登录访问需授权页面重定向至登录页，URL保留目标路径，登录后跳回
会话超时（30分钟无操作）自动退出，提示重新登录；未保存的草稿内容不丢失（存入本地或草稿表）
边界 密码修改后已有Session其他已登录设备/标签页的Session保持有效，但涉及敏感操作（如审批）时重新校验密码
边界 同一账号多设备登录允许同一账号在不同设备同时登录，但编辑同一资源时后操作者收到冲突提示
边界 用户在提交表单时Session过期弹出"登录已过期，请重新登录"弹窗，登录后保留表单已填写内容并继续提交
边界 密码输入框粘贴空格前端trim去除首尾空格后再提交，但密码内部空格保留
边界 密码修改后使用旧密码登录拒绝，提示"密码错误"（不提示"密码已修改"）
边界 账号被管理员手动禁用登录时提示"账号已被禁用，请联系管理员"，不暴露禁用原因
边界 同一浏览器同时登录不同角色不推荐，但允许。切换角色时清除前一个角色的缓存权限
边界 登录页面长时间闲置登录页面自身设置较短超时（如10分钟），超时后清除已填内容

3.1.4 异常处理

异常处理方式
数据库连接失败提示"系统繁忙，请稍后重试"
密码加密失败记录日志，提示"注册失败，请联系管理员"
边界 Token被篡改或过期清除本地Token，跳转至登录页，不给出具体错误原因
边界 同一秒内大量并发登录请求Redis分布式限流，单IP每秒≤5次，超限返回"操作过于频繁"
边界 登录时用户角色数据损坏拒绝登录，提示"账号信息异常，请联系管理员"

3.2 辅导员端 — 文档上传与自动解析

3.2.1 功能描述

辅导员上传政策通知文档，系统自动完成结构化字段提取和全文向量化入库。

3.2.2 功能细节

上传要求：

项目说明
支持格式PDF、Word（.docx）、扫描件PDF（自动OCR识别）
必填标签适用年级（如"2023级、2024级"）、项目分类
文件大小限制≤ 20MB

3.2.3 边界条件

场景处理方式
上传文件为空或损坏提示"文件无效，请重新上传"
文件格式不支持提示"仅支持PDF和Word格式"
文件超过20MB提示"文件过大，请压缩后上传"
LLM提取字段为空该字段标记为"⚠️ 未识别，请手动填写"
LLM提取置信度 < 80%该字段橙色高亮，提示导员重点核对
边界 文件名含非法字符（\ / : * ? < > |）自动过滤非法字符，或提示"文件名包含非法字符，请重命名"
边界 文件名超长（≥200字符）截断至200字符，保留扩展名
边界 上传过程中网络中断前端显示"上传中断"，保留已上传部分，支持断点续传（≥10MB自动启用）
边界 上传完成后导员立即关闭浏览器（解析未完成）解析为异步任务，后台继续执行，完成后通过通知提醒导员前往预览
边界 同一文档被重复上传计算文件MD5哈希，命中已有记录时提示"该文档已上传过，是否覆盖？"
边界 文档内容为空（全空白页）MinerU解析后文本为空，提示"文档内容为空，请上传有效文档"
边界 文档为扫描件但OCR完全失败提示"OCR识别失败，请上传文字版PDF或手动输入关键信息"
边界 文档有密码保护/加密提示"文档已加密，请先解密后上传"
边界 文档包含大量表格/复杂排版LLM提取后，表格内容以Markdown格式呈现，导员在预览页核对
边界 文档页数过多（≥100页）提示"文档页数较多，解析时间可能较长"，异步处理，完成后通知
边界 上传的文件名包含敏感词（如"机密""内部"）提示"文件名包含敏感信息，请重命名后上传"
边界 上传文件含病毒/恶意代码ClamAV扫描，拦截并隔离，提示"上传文件存在安全风险"
边界 适用年级格式不合法（如"2023级"写成"23级"）前端校验格式，提示"请使用完整年份格式，如'2023级'"
边界 适用年级范围覆盖所有年级（如"2021级、2022级、2023级、2024级"）正常处理，但UI上可简化为"全部年级"
边界 文档语言为纯英文或中英混合LLM正常提取，但提取结果可能为英文，导员可在预览页修改
边界 同时上传多个文件（批量上传）支持排队上传，并行处理数≤3，超出排队等待
边界 磁盘空间不足无法存储提示"存储空间不足，请联系管理员"，保留上传记录但标记为"存储失败"
边界 解析耗时超过5分钟前端显示"解析时间较长，请耐心等待"，后台继续，完成后通知
边界 导员在上传过程中点击"取消"或"返回"确认弹窗"取消上传将丢弃已上传内容，确认取消？"

3.2.4 异常处理

异常处理方式
LLM服务不可用提示"解析服务暂时不可用，请稍后重试"，保留草稿
向量化服务不可用禁止发布。提示"向量化服务暂时不可用"，保留草稿态，等待恢复后自动重试
向量化入库失败整体事务回滚，元数据和向量数据均不入库
OCR识别失败提示"文档文字识别失败，请上传文字版PDF或手动输入"
边界 LLM返回结果JSON格式解析失败重试最多3次，仍失败则所有字段标记为"⚠️ 未识别，请手动填写"
边界 MinerU服务崩溃自动切换至Unstructured作为降级方案，切换过程对用户无感
边界 提取的截止时间格式无法解析标记为"⚠️ 时间格式无法识别，请手动填写"，展示原始文本供参考
边界 材料清单提取为空但文档确实有清单标记为"⚠️ 未识别，请手动填写"，建议导员从文档中复制
边界 文件存储服务写入失败提示"文件存储失败，请稍后重试"，不占用上传次数
边界 上传队列已满（≥10个排队）提示"上传队列已满，请等待当前任务完成后再试"

3.3 辅导员端 — 解析预览与发布管理

3.3.1 功能描述

导员核对系统提取的结构化信息，确认无误后发布政策。

3.3.2 功能细节

  • 展示所有提取的结构化字段，低置信度橙色高亮，空值字段提示
  • 可点击编辑、增删材料清单
  • 确认发布或保存草稿

3.3.3 边界条件

场景处理方式
必填字段（项目名称、截止时间、材料清单）为空禁止发布，提示"请完善必填信息"，具体指出哪些字段为空
截止时间早于当前时间警告"截止时间已过期，请确认"，但允许强制发布（用于已过期政策的补发场景）
同一项目已存在生效政策警告"旧版政策将被自动归档，是否继续？"
边界 导员编辑时自动保存草稿失败前端显示"自动保存失败"红色提示，每30秒重试一次，允许手动保存
边界 导员同时打开多个标签页编辑同一草稿后保存的版本覆盖先保存的版本，并提示"另一标签页已更新此草稿"
边界 导员修改后未保存就离开页面监听beforeunload事件，提示"有未保存的更改，确定离开？"
边界 截止时间恰好等于当前时间视为有效，但提示"截止时间已到，请注意时效"
边界 发布后立即发现错误需要撤回提供"撤回发布"功能（发布后30分钟内可撤回），撤回后恢复为草稿态
边界 材料清单中某项材料名称超长（≥200字符）截断至200字符，完整内容在tooltip中展示
边界 导员手动输入的截止时间格式不合法实时校验，提示"请输入正确的日期时间格式"
边界 多个导员同时发布同一项目政策数据库乐观锁，后提交者收到"该政策已被其他导员更新，请刷新后重试"
边界 发布时 MySQL 写入成功但向量库写入失败事务回滚，政策保持草稿态，提示"发布失败，请稍后重试"
边界 发布后向量库中部分chunk丢失定时巡检任务检测向量库完整性，发现缺失自动重新向量化
边界 导员删除材料清单中的某项，但已发布政策的已有申请正在使用该清单旧申请仍使用旧版清单，新申请使用新版清单（版本化设计）
边界 项目分类选择后，导员发现分类有误允许在发布前修改，发布后如需修改需撤回后编辑

3.3.4 异常处理

异常处理方式
边界 发布事务执行中途数据库宕机事务自动回滚，下次进入页面时提示"上次发布未完成，请重新操作"
边界 草稿保存时MySQL写入失败前端立即提示"保存失败，请重试"，同时将草稿缓存到localStorage作为兜底
边界 发布后MQ消息（通知推送）发送失败消息进入死信队列，手动重试或定时任务自动重试

3.4 辅导员端 — 电子版初审

3.4.1 功能描述

辅导员在线初审学生提交的电子版材料，按项目分类查看和处理。

3.4.2 功能细节

项目分类视图 → 学生申请列表 → 审核详情页（预览、下载、通过/需修正）

3.4.3 边界条件

场景处理方式
待初审列表为空显示"暂无待初审申请"，提供"查看已审记录"的入口
学生未上传任何材料不进入待初审列表（"提交电子版"按钮不可用，直到至少上传一项材料）
导员未填写修正意见直接退回强制要求填写意见，至少10个字符，可提供常用意见模板
边界 学生上传的文件无法预览（格式损坏）显示"文件预览不可用"，但导员仍可下载到本地查看
边界 导员正在审核时，学生撤回了申请页面实时提示"该申请已被学生撤回"，自动刷新列表
边界 导员审核时网络中断，已填写的审核意见丢失前端每30秒自动保存审核意见草稿到localStorage，恢复时弹出"恢复未提交的审核意见"
边界 批量初审时，部分学生合格、部分有问题批量通过只勾选合格的学生，不合格的单独处理
边界 学生上传的材料与政策要求明显不符（如传错文件）导员可在修正意见中注明，或直接退回要求重新上传
边界 导员误操作点了"初审通过"提供"撤销初审"功能（操作后30分钟内），撤销后恢复为"待初审"
边界 同一学生的同一政策多次提交申请系统自动去重，保留最新版本，旧版本标记为"已覆盖"
边界 导员审核时，另一导员已审核了该申请页面提示"该申请已被其他导员处理"，自动刷新列表
边界 学生提交的电子版材料中，部分文件能打开部分打不开可打开的文件正常预览，打不开的文件标注"预览失败"，导员可下载尝试
边界 待初审列表中学生申请超过100份分页加载，每页20条，支持按姓名/学号搜索
边界 学生提交的电子版材料超过政策要求的材料清单范围正常显示，导员在审核时只关注清单要求的材料，多余材料可忽略

3.4.4 异常处理

异常处理方式
边界 初审通过后，通知学生失败通知进入重试队列，最多重试3次，仍失败则记录日志，下次学生登录时在通知中心展示
边界 文件存储服务临时不可用，无法预览显示"文件服务暂时不可用"，导员可选择稍后重试或直接下载
边界 审核意见中包含敏感词提示"审核意见包含敏感词，请修改后提交"

3.5 辅导员端 — 纸质版终核

3.5.1 功能描述

辅导员终核学生提交的纸质版材料，重点检查材料齐全性与签章合规性。

3.5.2 功能细节

（保留V1.0内容）

3.5.3 边界条件

场景处理方式
纸质版缺少盖章退回修正，注明"缺少XX单位公章"
纸质版缺少签名退回修正，注明"缺少XX人签名"
材料不齐全退回修正，注明"缺少XX材料"
边界 学生点击"我已提交纸质版"但实际未提交系统记录提交时间，导员在终核时如未收到纸质版，可选择"退回，未收到纸质材料"
边界 纸质版材料与电子版内容不一致退回修正，注明"纸质版与电子版不一致，请核对后重新提交"
边界 学生提交纸质版后长期未处理（超过5个工作日）系统自动提醒导员"有纸质版待终核"，超过10个工作日升级提醒至校级管理员
边界 纸质版有涂改痕迹导员自行判断是否接受，如不接受退回修正并要求重新提交
边界 纸质版材料页数缺失退回修正，注明"缺少第XX页，请补充完整后提交"
边界 学生提交纸质版的截止时间已过系统在"我已提交纸质版"按钮上提示"纸质版提交截止时间已过，请联系辅导员确认是否仍可提交"，导员端显示超时标记
边界 纸质版中签章模糊无法辨认退回修正，注明"签章模糊不清，请重新盖章后提交"
边界 终核通过后，发现漏核了某项材料提供"撤销终核"功能（操作后30分钟内），撤销后恢复为"待终核"
边界 导员在终核时发现学生材料中使用了过期/错误的表格模板退回修正，注明"请使用最新版表格模板，可从政策附件中下载"
边界 学生先点击了"我已提交纸质版"后，又上传了新的电子版材料新上传的电子版材料不影响已提交的纸质版流程，但会在终核页面标注"电子版有更新"

3.5.4 异常处理

异常处理方式
边界 终核通过后，通知校级管理员失败通知进入重试队列，3次失败后记录日志，发送站内信给校级管理员
边界 终核退回后，学生的申请状态无法正确更新手动触发状态同步工具，或通过定时任务检测状态一致性

3.6 校级管理员 — 最终审批

3.6.1 功能描述

校级管理员对辅导员终核通过并提交上来的纸质版材料进行最终合规性审批。

3.6.2 功能细节

按项目分类 → 项目下按学院分组 → 审批详情页

3.6.3 边界条件

场景处理方式
待审批列表为空显示"暂无待审批申请"
审批驳回未填写理由强制要求填写驳回理由，至少10个字符
同一项目下某学院无申请该学院分组不显示

场景处理方式
所有用户输入长度超限前端限制输入长度，后端二次校验，超限时截断或拒绝
所有用户输入包含XSS攻击代码输出时转义HTML特殊字符，不存储原始HTML
所有用户输入包含SQL注入代码使用ORM参数化查询，禁用原生SQL拼接
所有用户输入包含特殊Unicode字符正常存储和展示，但搜索时做归一化处理
所有用户输入为纯空格trim后为空则视为无效输入
所有用户输入包含emoji数据库使用utf8mb4字符集，支持emoji存储
文件上传：MIME类型与实际内容不符MIME类型 + 魔数双重校验，双重不一致则拒绝
文件上传：文件名包含路径遍历（../）过滤"../"和"..\"等路径穿越字符

4.5 第三方服务依赖边界

场景处理方式
LLM API限流（Rate Limit）请求排队，等待后重试，前端显示"服务繁忙，请稍后"
LLM API费用超预算设置日调用上限，超限时降级或提示
LLM API返回空或错误重试最多3次，仍失败则标记为"未识别"
MinerU服务OOM自动重启，失败任务加入重试队列
Dify服务不可用Agent降级为关键词检索，其他功能不受影响
向量数据库连接超时重试3次，失败后降级为纯关键词检索
对象存储服务不可用（MinIO宕机）上传功能暂停，已上传文件可读（只读模式）
Redis宕机Session降级为数据库存储，缓存功能降级，限流功能降级
MySQL主从延迟写操作走主库，读操作允许从库延迟（最终一致性），关键读操作强制走主库

第5章 🆕 并发与冲突场景

5.1 并发场景矩阵

并发场景冲突类型解决方案
多个导员同时编辑同一政策草稿写写冲突乐观锁（version字段），后提交者提示"已被其他导员修改，请刷新"
导员审核时，学生撤回申请读写冲突导员端实时轮询（或WebSocket）状态变更，提交时二次校验状态有效性
导员初审时，其他导员已初审该申请写写冲突数据库行锁，已审核的申请不可再审核
学生同时提交多个材料写写冲突每个材料独立上传，事务隔离
批量审批时，部分申请已被其他人处理部分失败逐条处理，已处理的跳过，未处理的正常处理，返回处理结果汇总
学生提交电子版时，政策被归档读写冲突提交时校验政策状态，已归档则拒绝提交
统计看板数据与实时数据不一致读写冲突统计数据使用缓存/预计算，允许最多5分钟延迟
多个学生同时申请同一项目无直接冲突各自独立申请，互不影响
导员发布政策时，学生正在查看看板读写冲突看板下次刷新时自动展示新政策，无需实时同步
系统管理员导出数据时，数据正在被修改读写冲突导出使用快照读（SELECT ... FOR UPDATE 或事务隔离级别）
同一学生同一政策重复提交申请数据重复唯一索引（user_id + policy_id），防止重复
通知批量推送时，大量用户同时在线并发推送消息队列削峰填谷，异步推送

5.2 乐观锁设计

对于存在写冲突的核心资源，使用乐观锁机制：

乐观锁实现方案
1. 在 policies 表增加 version 字段（INT，默认1）
2. 读取时获取 version
3. 更新时校验 version = 读取时的值
4. 更新时 version + 1
5. 如果影响行数为0，说明已被其他事务修改，提示冲突

受影响表：policies, policy_metadata, user_applications

5.3 分布式锁场景

场景锁粒度实现方式
同一政策发布policy_idRedis SETNX，过期时间30秒
同一学生同一政策申请user_id + policy_id数据库唯一索引（天然互斥）
文档解析任务调度上传文件IDRedis SETNX，过期时间10分钟
定时任务（如提醒通知）任务名称Redis分布式锁，防止多实例重复执行

第6章 🆕 状态异常恢复

6.1 状态异常场景

异常状态可能原因恢复策略
申请状态卡在"待初审"超过7天导员未处理系统自动发送提醒给导员，15天后升级提醒至校级管理员
申请状态卡在"待终核"超过10天导员未收到纸质版或未处理系统自动提醒导员，15天后升级提醒至校级管理员
申请状态卡在"已交校级待审批"超过15天校级管理员未处理系统自动提醒校级管理员，20天后升级提醒至超级管理员
申请状态为"需修正"但超过截止时间学生未及时修正状态自动变为"已过期"
申请状态为"准备中"但超过截止时间学生未及时提交状态自动变为"已过期"
政策为"已发布"但截止时间已过政策到期定时任务自动将政策状态改为"已归档"
申请状态显示"已完成"但实际校级审批未通过数据异常后台提供手动修正状态工具，供管理员使用
用户账号状态异常（如is_first_login与实际情况不符）数据不一致登录时自动校验并修正
通知推送失败导致状态不一致消息丢失定时任务扫描异常状态，补发通知
文件上传成功但数据库记录未更新事务部分失败定时任务扫描上传目录与数据库记录，修复不一致

6.2 状态自动修复策略

定时修复任务（每日凌晨3:00执行）
1. 扫描所有状态异常的申请记录
2. 扫描所有已过期的政策
3. 扫描文件存储与数据库记录的完整性
4. 扫描通知记录的一致性
5. 生成异常报告，通知管理员

自动修复规则：
- 超过截止时间 + 状态为"准备中" → 自动标记为"已过期"
- 超过截止时间 + 状态为"需修正" → 自动标记为"已过期"
- 政策截止时间已过 + 状态为"已发布" → 自动标记为"已归档"
- 申请状态为"已完成"但缺少校级审批记录 → 标记为"异常"，通知管理员人工处理

6.3 手动修正工具

为管理员提供申请状态手动修正界面：

  • 搜索申请（按学号、申请ID、政策名称）
  • 查看当前状态和状态流转历史
  • 手动变更状态（记录操作日志，标注为"管理员手动修正"）
  • 变更时自动校验状态流转合法性
  • 变更后自动通知相关用户

6.4 幂等性设计

操作幂等实现方案
提交电子版材料禁止重复提交，已提交状态不可再次提交
初审通过/退回检测当前状态，只有"待初审"状态可操作
终核通过/退回检测当前状态，只有"待终核"状态可操作
校级审批通过/驳回检测当前状态，只有"已交校级待审批"状态可操作
发布政策已发布政策不可再次发布，需先撤回
收藏政策已收藏再次点击等于取消收藏（toggle）
通知推送同一事件不重复推送，使用事件ID去重
文件上传同一文件（MD5相同）在上传时提示"已存在同名文件，是否覆盖"
