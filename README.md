# 校事通 — 智能政策问答平台

## 项目简介

面向高校师生的智能政策问答与多级申请协同平台。辅导员上传政策文档，系统自动提取结构化信息，学生可通过智能问答查询政策，并在线完成申请全流程跟踪。

## 技术栈

| 层级 | 技术选型 |
|:----|:---------|
| 前端 | Vue 3 + Vite + Element Plus + TypeScript |
| 后端 | FastAPI (Python 3.10) |
| 数据库 | PostgreSQL 16 + pgvector |
| LLM | DeepSeek Chat API |
| Embedding | 通义千问 text-embedding-v2 (DashScope) |
| 密碼 | bcrypt + JWT |

## 快速启动

```bash
# 1. 启动数据库
docker compose up -d

# 2. 配置环境变量
cp backend/.env.example backend/.env
# 编辑 .env 填入 API Key

# 3. 后端
cd backend
pip install -r requirements.txt
python scripts/seed.py           # 创建默认管理员
python -m uvicorn app.main:app --port 8000

# 4. 前端
cd frontend
npm install
npx vite --port 5173
```
